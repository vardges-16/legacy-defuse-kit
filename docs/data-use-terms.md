# Data use terms: Legacy Defuse Kit data products

Applies to the Purview data products **FinOps Cost & Budget** and **Trust Ledger** (governance domain *Legacy Defuse Kit*). By requesting access you agree to the following:

1. **Stated purpose only.** Use the data only for the usage purpose you selected in the access request (for example financial reporting, chargeback / showback, budget planning, audit, data quality monitoring, pipeline operations).
2. **No copies.** Do not export or copy the data outside the approved Fabric items (`wh_gold`, `lh_trust`, `sm_finops`, `rpt_finops_executive`). Copies are not permitted by the access policy.
3. **Personal data.** Owner names and emails are hashed before Silver. Do not try to re-identify people or join the data with personal data from other sources.
4. **No external sharing.** Do not share the data, screenshots of it or extracts outside Zontique.
5. **Time limit.** Access expires after 90 days; request again if you still need it.
6. **Report issues.** If figures look wrong, check the Trust Ledger (reconciliation status, quarantine) and contact the data product owner before using them.

Owner: Legacy Defuse Kit data product owner (team de_dust2).
